# 달랏 베트남어

달랏 이주를 준비하며 베트남어를 처음부터 배우기 위한 웹앱(PWA)입니다. 아이폰 홈 화면에 추가하면 앱처럼, 인터넷 없이도 쓸 수 있습니다.

## 학습 순서 (12주)
1. **1–2주차**: 알파벳, 발음, 6성조 (성조 탭의 듣기 퀴즈)
2. **3–6주차**: 인사, 숫자·돈, 카페, 식당, 시장 흥정, 그랩·길 묻기
3. **7–10주차**: 집 구하기, 오토바이, 장보기, 유심·은행, 병원, 긴급 상황
4. **11–12주차**: 날씨·이웃과 대화, 총복습, 1.0배속 듣기

매일 새 문장 10개를 배우고, 간격 반복(FSRS)으로 잊어버릴 때쯤 다시 복습합니다.

## 기능
- 성조 트레이너: 음높이 그림, 성조만 다른 단어 듣기, 듣고 성조 맞히기, 문장 속 성조 표기 고르기
- 달랏 생활 장면 14개, 문장 300여 개 (북부·남부 단어 차이, 한자어 힌트 포함)
- 모든 문장·단어의 베트남어 녹음 내장 (맥 Linh 음성, 오프라인 재생), 느리게 듣기, 내 발음 녹음 후 비교
- 학습 기록은 이 기기에만 저장되며, 백업 파일로 내보내고 불러올 수 있습니다.

## 개발
```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # 배포용 빌드 (dist/)
npm run ios      # (맥 전용) 아이폰 앱 빌드 후 Xcode 열기
npm run audio    # (맥 전용) 새로 추가한 문장을 Linh 음성으로 녹음해 public/audio에 저장
```

문장이나 단어를 추가·수정하면 맥에서 `npm run audio`를 실행해 녹음 파일을 함께 커밋하세요. 녹음이 빠지면 테스트(`tests/audio.test.ts`)가 실패해서 배포되지 않습니다.

`main` 브랜치에 push하면 GitHub Actions가 GitHub Pages로 배포합니다.

## 근처 채팅 (아이폰 앱)
💬 채팅 탭은 근처 아이폰끼리 블루투스·와이파이 직접 연결(애플 MultipeerConnectivity)로 대화합니다. 인터넷은 필요 없습니다.
보낼 베트남어를 쓰거나 앱 문장에서 고른 뒤 🎤로 소리 내어 읽으면, 음성인식 결과가 **성조까지 똑같을 때만** 메시지가 보내집니다. 틀린 음절은 성조(주황)·소리(빨강)로 표시됩니다.

웹(홈 화면 추가)에서는 블루투스를 쓸 수 없어서, 이 기능은 Xcode로 설치한 아이폰 앱에서만 동작합니다.

1. 맥에서 `npm run ios` (웹 빌드 → `ios/` 프로젝트에 복사 → Xcode 열기)
2. Xcode에서 App 타깃 > Signing & Capabilities > Team에 내 Apple ID 선택
3. 아이폰을 케이블로 연결하고 ▶ 실행 (무료 Apple ID는 7일마다 다시 설치해야 합니다)
4. 처음 실행할 때 로컬 네트워크·마이크·음성 인식 권한을 허용하세요. 두 아이폰 모두 블루투스와 와이파이를 켜 둡니다.

베트남어 음성인식을 기기 안에서 못 하는 아이폰은 인식할 때 인터넷이 필요할 수 있습니다.
