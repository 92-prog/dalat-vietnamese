# 달랏 베트남어

달랏 이주를 준비하며 베트남어를 처음부터 배우기 위한 웹앱(PWA)입니다. 아이폰 홈 화면에 추가하면 앱처럼, 인터넷 없이도 쓸 수 있습니다.

## 학습 순서 (12주)
1. **1–2주차**: 알파벳, 발음, 6성조 (성조 탭의 듣기 퀴즈)
2. **3–6주차**: 인사, 숫자·돈, 카페, 식당, 시장 흥정, 그랩·길 묻기
3. **7–10주차**: 집 구하기, 오토바이, 장보기, 유심·은행, 병원, 긴급 상황
4. **11–12주차**: 날씨·이웃과 대화, 총복습, 1.0배속 듣기

매일 새 문장 10개를 배우고, 간격 반복(FSRS)으로 잊어버릴 때쯤 다시 복습합니다.

## 기능
- 성조 트레이너: 음높이 그림, 성조만 다른 단어 듣기, 듣고 성조 맞히기, 문장 속 성조 표기 고르기
- 달랏 생활 장면 14개, 문장 300여 개 (북부·남부 단어 차이, 한자어 힌트 포함)
- 기기 음성으로 듣기·느리게 듣기, 내 발음 녹음 후 비교
- 학습 기록은 이 기기에만 저장되며, 백업 파일로 내보내고 불러올 수 있습니다.

## 개발
```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # 배포용 빌드 (dist/)
```

`main` 브랜치에 push하면 GitHub Actions가 GitHub Pages로 배포합니다.
